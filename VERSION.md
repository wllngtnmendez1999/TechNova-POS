
# Nota técnica de versión – TechNova POS

## Versión documental v0.1.0

**Sistema:** TechNova – Sistema de Punto de Ventas (POS)

**Fecha:** 11 de octubre de 2026

**Estado:** Cierre de documentación y diseño inicial.

## 1. Contenido de la versión

La versión v0.1.0 reúne las principales evidencias técnicas elaboradas durante la asignatura de Ingeniería de Software.

Incluye los requisitos funcionales, historias de usuario, modelos UML, arquitectura inicial, documentación de gestión del proyecto y registro de cambios.

También incorpora la organización de las evidencias en el repositorio de GitHub y el seguimiento de actividades mediante GitHub Projects e Issues.

Esta versión representa una base documental para continuar el desarrollo del sistema, no una aplicación comercial completamente implementada.

## 2. Cambios controlados

Durante el proyecto se registraron cinco avances principales:

1. Definición de requisitos funcionales e historias de usuario.
2. Elaboración de diagramas UML.
3. Selección de arquitectura por capas.
4. Organización de tareas, prioridades y responsables en GitHub Projects.
5. Consolidación de la documentación técnica y del repositorio.

Estos avances se encuentran descritos en el archivo CHANGELOG.md.

## 4. Aspectos pendientes

- Completar las funcionalidades que todavía se encuentran en desarrollo.
- Implementar y validar la estructura de la base de datos.
- Desarrollar el módulo de ventas.

## 5. Próximo paso técnico

El próximo paso será continuar con el desarrollo de los módulos prioritarios y la implementación de la base de datos, tomando como referencia los requisitos y diagramas elaborados.

Posteriormente se realizarán las pruebas necesarias para comprobar la comunicación entre los componentes y el funcionamiento de las operaciones principales.

## 6. Observación final

La versión v0.1.0 constituye un punto de referencia para el control documental del proyecto TechNova POS.

Su propósito es conservar las decisiones, evidencias y avances realizados durante la asignatura, facilitando la continuidad del desarrollo en futuras etapas.
